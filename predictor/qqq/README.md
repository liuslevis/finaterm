# QQQ 定投因子训练数据

## Idea

对定投：建议盯的优先级
值得每周/每月看（能解释大亏季）：
1. 10Y 与 10Y 实际利率 —— 单季或 8–12 周内是否出现 >50–75bp 的单向冲击；10Y涨—>贴现率上升（收紧）->QQQ公司估值下降
2. HY 信用利差是否急扩（不是水平高一点）。TradingView：FRED:BAMLH0A0HYM2（ICE BofA 美国高收益债 OAS）。高收益债，就是垃圾债，违约风险高。利差扩大 = 市场觉得这些公司更可能还不起钱、风险偏好在降温，金融条件在收紧。
3. Fed （隔夜利率）路径的预期差（降息次数被砍 / 重新加息） 。TradingView搜索：FRED:FEDFUNDS 或 FRED:EFFR：有效联邦基金利率 ；ECONOMICS:USINTR：政策利率
4. QQQ 前十大的盈利修正方向。十大：NVDA AAPL GOOGL MSFT MU AMZN AMD AVGO META TSLA。TradingView 打开一只权重股如 NVDA（不要打开 QQQ 本身）：顶部点 Forecasts（预测），再点 Actuals and estimates（实际值与预估），指标选 EPS，周期选 Yearly（年），看 FY1 / 下一财年 那条，示例页长这样：Forecasts → Actuals and estimates。图上那条 Average estimate（分析师均值）随时间走的线 就是修正方向：线往上 → 盈利在上修；线往下 → 盈利在下修；横盘 → 没有信息量
5. 美元急升是否叠加 1–3（金融条件收紧）。TradingView搜索 TVC:DX US Dollar Index（美元指数，美元对一篮子货币，欧元权重最大）
6. QQQ 权重里真正砸 AI 基建的 capex（不是十大 capex 相加）。盯 MSFT / AMZN / GOOGL / META 当季现金 PP&E 与全年指引；NVDA 等是卖方。公司不拆「纯 AI capex」，用总现金 capex，2023 后增量电话会归因于 AI/云。这是结构/叙事因子，不是「避开大亏季」的冲击指标。
7. 地缘冲突冲击（俄乌 / 巴以 / 美伊）——只记样本期内 **5 场最大冲击**，不是「战争还在打」或所有升级。
不值得用来“避开某季度”：
* 单一 PE、单一 CPI 绝对值、日历季节性、VIX 高低、Fed 开会当天、capex **水平**本身

样本文件：[`qqq_dca_train.csv`](qqq_dca_train.csv)

用于解释 **QQQ 单季涨跌**（`label`），不是择时避开某一季的交易信号。因子与 `label` 为**同期**，详见 [同期解释 vs 预测](#同期解释-vs-预测勿误会)。盯盘优先级与列对应关系如下。

值得每周/每月看（能解释大亏季）：

1. **10Y 与 10Y 实际利率** → `factor1`  
   单季或 8–12 周内是否出现 **>50–75bp** 的单向冲击。10Y 涨 → 贴现率上升（收紧）→ QQQ 公司估值下降。
2. **HY 信用利差是否急扩**（不是水平高一点）→ `factor2`  
   序列：FRED `BAMLH0A0HYM2`（ICE BofA 美国高收益债 OAS）。利差扩大 = 风险偏好降温、金融条件收紧。
3. **Fed（隔夜利率）路径的预期差** → `factor3`  
   降息次数被砍 / 重新加息。落地利率用 FRED `FEDFUNDS`；预期差本身未单独成列（见下方注意）。
4. **QQQ 前十大盈利修正方向** → `factor4`  
   十大：NVDA AAPL GOOGL MSFT MU AMZN AMD AVGO META TSLA。看 FY1 EPS 分析师均值：上修 / 下修 / 横盘（横盘无信息量，记 0）。
5. **美元急升是否叠加 1–3** → `factor5`  
   TVC:DXY（美元指数）。
6. **QQQ 权重股里真正砸 AI 基建的 capex** → `factor6`  
   MSFT + AMZN + GOOGL + META 当季现金 PP&E（$B）。NVDA/AVGO/AMD/MU 是卖方、自身 capex 很小；AAPL/TSLA 不是同量级的 GPU/数据中心买家。公司不披露「纯 AI capex」，用总现金 capex：2023 之后的增量公司自己归因于 AI/云基建。
7. **地缘冲突（俄乌 / 巴以 / 美伊）** → `factor7` / `factor7_comment`  
   `1` 只留样本期内五场最大冲击（苏莱曼尼、俄乌开战、10/7、十二日战争、2026Q1 美以打伊朗/霍尔木兹）。其余开战、直接对打、停火破裂、消耗战一律 0。备注只写这五场，不进树。

不值得用来「避开某季度」：单一 PE、单一 CPI 绝对值、日历季节性、VIX 高低、Fed 开会当天、capex 水平本身、战争还在打的水平本身。

覆盖区间：2020Q1–2026Q3，共 27 行。2026Q3 的 `label` 为季未完值（−3.76）；`factor6` 为空（四家 10-Q 未出）。CSV 列名是 `factor1`（文档里的 `lfactor1` 同列）。`qqq_dca_test.csv` 与 train 同表；`decision_tree.py` 按 id 1–20 / 21–27 切，并丢掉 `factor6` 为空的行，故测试集实际是 2025Q1–2026Q2（6 行）。

## 列说明

| 列 | 含义 | 单位 / 取值 | 计算 |
|---|---|---|---|
| `id` | 样本序号 | 1–27 | 按时间升序 |
| `year` | 年 | 2020–2026 | |
| `quarter` | 季 | 1–4 | |
| `factor1`（文档或称 `lfactor1`） | 10Y 名义利率季末变动 | **bp**；正 = 收紧 | 与分析表中的 Δ10Y 一致（季末对上季末） |
| `factor2` | HY OAS 急扩幅度 | **bp**；正 = 急扩 | 当季日内/月度 **高点 − 上季末收盘**（BAMLH0A0HYM2） |
| `factor3` | 政策利率已落地变动 | **bp**；正 = 加息 | `FEDFUNDS` 当季末月 − 上季末月（有效联邦基金利率月度） |
| `factor4` | 前十大 FY1 EPS 共识修正 | `1` 上修 / `-1` 下修 / `0` 无信息或混杂 | 仅在均值有方向且人数未崩时记 ±1；横盘不记 |
| `factor5` | 美元指数季末变动 | **%**；正 = 美元升 | DXY 当季末 / 上季末 − 1，再 ×100 |
| `factor6` | 四大 hyperscaler 当季现金 capex | **$B** | 见下方 [factor6 口径](#factor6) |
| `factor7` | 当季是否出现俄乌 / 巴以 / 美伊冲击 | `1` / `0` | 见下方 [factor7 口径](#factor7) |
| `factor7_comment` | 事件备注 | 文本 | 不进 `decision_tree.py` |
| `label` | QQQ 当季涨跌 | **%** | 分析表中的季度收益 |

## 编码约定

- **急扩看增量，不看水平。** `factor2` 用季内高点相对上季末，避免 2023Q4 那种「季末 Δ 骗人」（利差先冲后回）被抹平。10Y 的 `factor1` 仍用季末 Δ，与原分析表对齐；2023Q4 季末 +30bp 会低估 10 月峰值（约 5.02% 后回落 >100bp）。
- **`factor4=0` 表示没有增量信息**（横盘、覆盖不足、或权重股方向互相抵消，例如 2026Q3 半导体上修但 META/TSLA 下修）。不要把 0 解释成「盈利稳定」。
- **`factor3` 是已落地的隔夜利率，不是期货隐含路径。** 2024Q3 首降 50bp 已定价，落地为负但 QQQ 只小涨；2026Q3 落地仍为 0，但就业超预期后降息预期被砍、开始定价加息。若要建模「预期差」，需另接 FedWatch / 期货，不要把本列当成预期差。
- **`factor6` 是水平，不是 Δ。** 约 20B（2020）→ 165B（2026Q2）。树很容易按「是否已进入 AI 大开支期」切一刀，等于时间戳，不是当季冲击。QoQ/YoY 要另算。空值只出现在尚未出 10-Q 的季。
- **`factor7` 只记五场最大，不记「有冲突」。** 2021Q2 十一日战争、2024 年伊以/以黎对打、2025Q1 / 2026Q3 停火破裂都不进列。开战之后的消耗战更不进。若把升级季都标 1，列会变密、接近时间戳。

## 同期解释 vs 预测（勿误会）

每一行都是 **当季因子 ↔ 当季 `label`**：`factor*` 与 QQQ 季度收益在**同一窗口**里走完，不是「季初已知道的信息 → 再等出当季涨跌」。`decision_tree.py` 也是同一行拟合同一行；测试集准确率是 **in-quarter 解释**，不是可交易预测成绩。

**时间对齐**

| 列 | 何时才算完 | 与 `label` |
|---|---|---|
| `factor1` / `lfactor1` | **季末** 10Y 相对上季末的 Δ | 同一季一起实现 |
| `factor2` | 当季 **高点** − 上季末 | 急扩常与暴跌同一周；季中才知道峰值 |
| `factor3` | **当季末月** FEDFUNDS − 上季末月 | 同一季落地 |
| `factor4` | 当季共识上修 / 下修 | 常与行情同步（股价动了分析师才修） |
| `factor5` | **季末** DXY / 上季末 | 同一季走完 |
| `factor6` | **季后** 10-Q/10-K 才有当季现金数；季内市场交易的是指引 | 比 `label` 更晚完整；季中可知的是指引/电话会，不是本列 |
| `factor7` | **当季** 新闻冲击走完才钉死；季中爆发则当季后半已知 | 与 `label` 同一窗口；爆发周常与风险偏好冲击重叠 |

唯一季前已知的锚是 **上季末** 的利率 / HY / DXY 水平，以及 **上季已披露** 的 capex。增量、急扩、当季修正、当季 capex 实际值都不是季初信息。

**算不算泄露**

- **不是**经典 target leakage：没有把 QQQ 收益写进特征。
- **是** look-ahead（若当预测）：用了 `label` **发生时** 才完整的同期冲击。`factor2` 尤其明显——HY 急扩与 QQQ 大跌经常是同一风险偏好冲击。`factor6` 更晚：现金 capex 在季后财报才钉死，当季行情已经走完。`factor7` 同样同期：开战周常与当季跌重叠（如 2022Q1、2026Q1），不是季初已知。
- 因此：季后复盘 / 相关与规则描述 → 现在对齐合理。声称「季初就能避开这一季」→ 不合格。

**不要默认改成「Q2 因子 → Q3 `label`」**

机制是当季定价（10Y 这季涨 → 估值这季压），不是稳定的一季滞后。滞后训练的是冲击**之后**（常含反弹，如 2020Q1 压力 vs 2020Q2 +30%），会丢掉真正要解释的大亏季（如 2022Q2 的急扩应配 2022Q2 的 −22.5%）。n≈27，再滞后更噪。

**这套表能做什么、不能做什么**

| 做法 | 是不是预测 | 说明 |
|---|---|---|
| 当季 `factor*` → 当季 `label`（现在） | 否 | 同期共变：解释 / 相关，不是因果证明，更不是季初信号 |
| 上季已收盘因子 → 下一季 `label` | 是 | 无当季泄露；这些列对下一季往往很弱 |
| 季初已知水平、FedWatch 等 → 当季收益 | 是 | 须另做特征，不能直接用现在的 Δ / 急扩 |
| 本季前几周已发生的冲击 → 余下收益 | 是（短窗） | 接近上文「8–12 周盯冲击」；仍不是避开整季 |

不是「树不能预测」，是 **CSV 的时间对齐不能当预测**。改成预测后仍应预期弱：样本少，冲击多半当季定价，README 的因子优先级本就不是为「避开某一季」设计的。不要把当前 test accuracy 当成预测能力。

## 使用时注意

- **先读「同期解释 vs 预测」**：本表是当季对当季；不能当季初预测，也不要把树的测试准确率当成可交易成绩。
- 样本少（n=27），只适合规则/描述统计，不适合深度模型。
- 2025 年 HY 峰值 **461bp 出现在 4/7，属于 Q2**；Q1 最高记到 355bp。
- 2026Q2 的 DXY 月度序列缺 5 月，季末用 6 月可得收盘。
- 正负号：`factor1` / `factor2` / `factor3` / `factor5` 为正表示金融条件偏紧方向；`factor4` 为正表示盈利上修；`factor6` 越大表示当季现金 capex 越高；`factor7=1` 只表示当季属于五场最大冲击之一（不是方向，涨跌都可能）；`label` 为正表示 QQQ 当季上涨。
- `factor7=1` **不蕴含** QQQ 当季必跌：2023Q4 的 10/7、2025Q2 十二日战争当季 `label` 仍为正。列只标记这五场是否出现。

## factor6 口径（MSFT + AMZN + GOOGL + META 现金 PP&E）

<a id="factor6"></a>

**为什么是这四家，不是 QQQ 前十合计**

| 纳入 | 角色 |
|---|---|
| MSFT、AMZN、GOOGL、META | QQQ 权重股里买 GPU / 建数据中心的需求方，公开 capex 序列完整、量级主导 |
| 不纳入 NVDA、AVGO、AMD、MU | 卖方；自身 PP&E 大约每季 1–3B，加进去几乎不动合计 |
| 不纳入 AAPL、TSLA | 不是同量级的 AI 基建买家 |
| 不纳入 ORCL | Epoch 等 hyperscaler 序列常含 Oracle，但不是 QQQ 前十大 |

公司不披露审计过的「AI capex」。本列 = 现金流量表 **购买物业厂房设备的现金**（不是 earnings 电话会里各家定义不同的 “capex”，也不含融资租赁）。2023 之后合计从 ~33B/季升到 2026Q2 的 165B，增量被公司归因于 AI/云基建；2020–2022 含亚马逊物流产能，不是纯 AI。

**怎么算**

- 标签：MSFT / GOOGL / META 用 `us-gaap:PaymentsToAcquirePropertyPlantAndEquipment`；AMZN 用 `PaymentsToAcquireProductiveAssets`。
- 来源：`https://data.sec.gov/api/xbrl/companyfacts/CIK….json`，只取 10-Q / 10-K。
- 单季：优先用约 90 天的期间值；否则用同一财年起点的 Q1 / H1 / 9M / FY 累计相减。
- 微软财年截止 6/30：FY Q1（7–9 月）→ 日历 Q3，FY Q2 → 日历 Q4，FY Q3 → 日历 Q1，FY Q4 → 日历 Q2。
- 单位 $B，四舍五入到两位。2026Q3 空着，等四家季报。

**和网上图表的差别**

[Epoch AI](https://epoch.ai/data-insights/hyperscaler-capex-trend) / [Visual Capitalist](https://www.visualcapitalist.com/visualized-big-tech-ai-spending/) 用现金 PP&E **加** 当年新增融资租赁，且常含 Oracle，所以同季数字更大（例如他们 2025Q4 五家约 141B；本列四家现金 118.6B）。现金口径 2020Q1 就能对齐，适合整张表。

## factor7 口径（俄乌 / 巴以 / 美伊，仅五场最大）

<a id="factor7"></a>

事先只留量级最大的五场：国家间开战或美伊直接打核设施 / 斩首 / 霍尔木兹中断。短战争、被拦截的对打、以黎升级、停火破裂不记。`factor7_comment` 仅这五行为非空。

**`factor7=1`（5/27）**

| 季 | 主事件 |
|---|---|
| 2020Q1 | 美伊：苏莱曼尼 / 伊朗打美军基地 |
| 2022Q1 | 俄乌全面入侵 |
| 2023Q4 | 10/7 加沙战争爆发 |
| 2025Q2 | 以伊十二日战争 + 美打福尔多等核设施 |
| 2026Q1 | 美以打伊朗、打死哈梅内伊、霍尔木兹实质中断 |

**刻意记 0 的冲击（有事件、不够大）**

2021Q2 巴以十一日战争；2024Q2 / 2024Q4 伊以直接对打（多被拦截）；2024Q3 以黎；2025Q1 加沙停火破裂；2026Q3 美伊停火再破、打商船（季未完）。消耗战、动员、峰会、停火生效同样是 0。
