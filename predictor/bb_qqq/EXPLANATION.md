# bb_qqq — 节目能否解释「前日 / 当日」收盘走势

样本：37 集 Bloomberg Surveillance（36 个播出日，2026-08-31 – 2026-10-29），QQQ / SPY 日线，
美债 2Y/10Y（akshare `bond_zh_us_rate`），Brent / WTI（akshare `futures_foreign_hist`）。
代码：`explain_extract.py`（LLM 只读转写，抽取"节目说了什么"）→ `explain_eval.py`（对照真实行情）。
产物：`data/explain/<BVID>.json`、`data/explain_panel.csv`、`reports/explain_metrics.json`。

这是**解释**（同期）问题，不是预测：不要求"不能穿越"，但要求**日期对齐**正确——这恰好是第一个发现。

---

## 一句话结论

| 窗口 | 能解释吗 | 关键数字 |
|---|---|---|
| **前日收盘**（P-1 收 → P 收，节目开播前已完成） | **能，方向准，幅度几乎不给** | 方向命中 SPY 25/30 = **83%**（p=0.0002），QQQ 21/29 = 72%；\|r\|≥0.5% 时 16/19 = 84%。10Y 方向 16/17 |
| **当日隔夜跳空**（P 收 → A 开，节目直播期间） | **能，几乎完美** | 节目报的期指 % vs QQQ 跳空 **r = 0.94**（R² 0.88，n=32），MAE 0.24pp，斜率≈1 |
| **当日收盘**（P 收 → A 收） | **能解释约 70%，全部来自跳空** | 期指 % → ret0 R² = **0.71**；用真实跳空本身 R² = 0.72 ——节目已经拿走了跳空里的全部信息 |
| **节目后盘中**（A 开 → A 收） | **基本不能** | 期指方向命中 15/33 = 45%（≈抛硬币）；trajectory r = 0.02。只有情绪有一条弱线索（见 §5） |
| **次日**（A 收 → A+1 收） | **不能** | 所有特征 \|r\| ≤ 0.10 —— 与 CORR.md "无方向预测力"一致 |

一句话：**节目是一份准确的"昨天发生了什么 + 今早期指在哪"的播报；当日收盘里由开盘前决定的那部分（约 57% 方差、70% R²）它都讲清楚了，开盘后的那部分它讲不了。**

---

## 1. 先修正日期：标题日期 = 实际播出日 + 1

B 站标题里的 `YYMMDD` 是**上传（北京）日期**，不是美东播出日期。三条独立证据：

1. **标题里有 7 个周六**（0905/0912/0919/0926/1003/1010/1024），没有一个周一；Surveillance 只在美股交易日直播。
2. **节目自报星期**：LLM 从转写里读出的 `air_weekday` 在 36 个可判定的集里 **35 个**等于 `标题日期 − 1 天` 的星期（唯一不符的 0911 集，LLM 读成 wednesday，实为 thursday）。
3. **行情对齐**：节目报的期指涨跌 vs QQQ 隔夜跳空

   | 对齐方式 | n | r | 95% CI |
   |---|---|---|---|
   | 播出日 = 标题 − 1 天 | 32 | **+0.94** | [+0.89, +0.97] |
   | 播出日 = 标题日期（原口径） | 25 | −0.01 | [−0.34, +0.29] |

   错一天，相关从 0.94 直接掉到 0。

**对因子研究（CORR.md）的影响**：原面板把 `show_date` 当作播出日，实际信号是**前一天**的。
这不构成穿越（信息只会更旧，偏保守），所以 CORR.md "没有方向预测力"的结论不受影响——本文 §4 的
"次日"列就是按正确对齐重做的 1 日 IC，仍然 ≈0。但 CORR.md 里的两个**诊断列** `ret_0` / `gap`
是错位的，"`preopen_tape≈0`、模型不是在复述盘面"那条判读是**错位造成的假象**：正确对齐后
`preopen_tape` 与跳空的 r = 0.78。

## 2. 前日收盘：方向复述准确，原因与行情方向一致

`prev_session` 字段：LLM 只记录节目对"上一个已完成交易日"明确说过的话。

| 项 | 结果 |
|---|---|
| 节目描述了前一交易日 | 34 / 37 集 |
| S&P 方向 vs SPY | **25/30 = 0.83**，Wilson CI [0.66, 0.93]，p=0.0002 |
| 方向 vs QQQ | 21/29 = 0.72，CI [0.54, 0.85]，p=0.012 |
| 同上，只看 \|QQQ\| ≥ 0.5% 的日子 | 16/19 = 0.84 |
| 10Y 方向 vs 实际 | **16/17 = 0.94** |
| 油价方向 vs Brent | 6/8 = 0.75 |
| 明确报了前日涨跌幅 | 仅 5 集（MAE 0.48pp）—— 节目很少报昨日收盘的百分比 |

**8 个 QQQ 方向"失误"的人工核查**（引文来自 LLM 抽取，可在 `data/explain/` 复核）：

| 被复盘的交易日（播出日） | 节目说 | QQQ / SPY 实际 | 判读 |
|---|---|---|---|
| 08-31（09-01） | "A few days of losses on the S&P close out August" | +0.05% / −0.30% | 说的是 S&P，SPY 方向对 |
| 09-16（09-17） | "banks falling out of bed yesterday" | +0.03% / −0.44% | 同上，SPY 对 |
| 09-29（09-30） | "Yesterday was tough" | +0.19% / −0.18% | 同上，SPY 对 |
| 09-30（10-01） | 季末、PCE 后抛售 | +0.25% / −0.21% | 同上，SPY 对 |
| 09-24（09-25） | "Three days now gains on the S&P" | −0.01% / −0.08% | 涨跌在 0 附近 |
| 09-03（09-04） | "Stocks ended lower Friday following a surprisingly strong August payroll report" | +1.19% / +1.05% | **真错**：周五早上的节目不可能知道周五收盘；该集（标题 0905）是唯一自报星期 unclear 的一集，疑似混入了别的时段/节目 |
| 09-15（09-16，两集） | "double digit gains yesterday on the S&P" / "Equities higher…" | −0.65% / −0.46% | **抽取或 ASR 错误**：两集都错，原句语境更像盈利增速而非前日涨跌 |

即：8 次里 4 次是节目讲 S&P、而 QQQ 与 S&P 分化，1 次涨跌≈0；**真正对不上的只有 2 个交易日（3 集）**。

### 节目给的"原因"站得住吗？

节目对前日行情给出的原因（LLM 归类，共 63 条，另有 other 1 条）：`earnings_ai` 17、`rates` 15、`fed` 8、`macro_data` 7、
`oil_energy` 6、`positioning_flows` 6、`geopolitics` 3。

**逐条方向核对**（"利率拖累"⇒ 10Y 应上行；"Fed 拖累"⇒ 2Y 应上行；"油价拖累"⇒ Brent 应上行）：

| 原因类别 | 可核对条数 | 与当天行情方向一致 |
|---|---|---|
| rates | 15 | 13（87%） |
| fed | 7 | 6（86%） |
| oil_energy | 6 | 5（83%） |
| 原因净方向 vs 当天 QQQ 涨跌 | 25 | 18（72%） |

**但横截面上，真正解释 QQQ 日收益的是油，不是利率**（36 个前日样本）：

| 宏观变量（同一交易日） | r 与 QQQ 日收益 | p |
|---|---|---|
| Brent % | **−0.63** | 0.0002 |
| 10Y Δbp | +0.07 | 0.69 |
| 2Y Δbp | +0.02 | 0.92 |
| 三者联合 OLS | R² 0.45，adj R² 0.40 | |

（Brent 用前后一日错位检查过：lag −1/0/+1 的 r = +0.07 / −0.56 / −0.02，同日对齐无误。）

**判读**：节目讲的每条原因**在方向上基本都对**（说利率拖累的那天利率确实涨了），
但它**分配的权重和数据不一致**——复盘前日时最常讲 AI/盈利与利率，油只排第 5；
而在这两个月里油价单变量就能解释 QQQ 日收益 ~39% 的方差，利率几乎为 0。
（注意：油在这里很可能是"伊朗/霍尔木兹地缘消息"的代理变量，节目在"今早"部分把 oil_energy +
geopolitics 列为第 2、4 大驱动，权重其实是给到了的，只是复盘昨天时没给。）

## 3. 当日：跳空讲得几乎完美，开盘后讲不了

`this_morning` 字段：节目直播时报的期指 / 利率 / 油价。没有任何一集的转写覆盖到 09:30 现货开盘
（录像中位 145 分钟，若从 06:00 开录约到 08:25；`cash_open.observed` 全部为 false，
全部转写尾部只有 1 处 "cash open" 字样且为前瞻语境），所以节目里不存在开盘后的信息。

### 3.1 跳空（P 收 → A 开）

| 特征 | n | r vs QQQ 跳空 | Spearman | 方向命中 |
|---|---|---|---|---|
| 节目报的期指 %（Nasdaq 优先，否则 S&P×1.2） | 32 | **+0.94** | +0.95 | **29/33 = 88%** |
| 日总结 `equity_futures`（brief 序数） | 36 | +0.87 | +0.91 | |
| `preopen_tape`（打分阶段 LLM 读的盘前走势） | 36 | +0.78 | +0.84 | |
| `p_up_1d`（打分阶段的"预测"） | 36 | +0.75 | +0.79 | |
| 节目情绪 `brief_sentiment` | 36 | +0.58 | +0.61 | |

期指数字的 MAE 0.24pp、回归斜率 0.99：**节目报的期指涨跌幅可以直接当跳空的估计值用。**
附带发现：打分阶段输出的 `p_up_1d` 与跳空 r=0.75 —— 所谓"1 日上涨概率"主要是在复述今早的期指。

### 3.2 当日收盘（P 收 → A 收）= 跳空 + 盘中

| 量 | 值 |
|---|---|
| Var(跳空) / Var(当日收益) | **0.57** |
| corr(跳空, 盘中) | +0.15（p=0.38，无显著延续/反转） |
| 真实跳空 → 当日收益 R² | 0.72 |
| **节目期指 % → 当日收益 R²** | **0.71** |
| 期指方向 → 当日收益方向 | 28/33 = 85% |
| 期指方向 → 盘中方向 | 15/33 = 45% |
| `trajectory`（节目期间期指走好/走坏）→ 盘中 | r = +0.02 |

节目把"跳空"这一块讲满了（0.71 vs 理论上限 0.72），剩下 ~30% 的当日变动来自开盘后，节目不可知。

## 4. 次日（A 收 → A+1 收）——按正确对齐重做

所有特征（期指、equity_futures、preopen、sentiment、composite、p_up_1d）与次日收益的 |r| ≤ 0.10，p ≥ 0.5。
与 CORR.md 的结论一致：**节目对下一个完整交易日没有方向信息**。

---

## 5. 唯一的弱线索：情绪 → 开盘后盘中（需外样本验证）

控制跳空后，情绪类特征对**当日开盘→收盘**仍有正向系数：

| 特征 | 盘中 r（QQQ） | 控制跳空后 t（QQQ / SPY） | 按符号分组的 QQQ 盘中均值 |
|---|---|---|---|
| `brief_sentiment` | +0.40（p=0.016） | **2.42 / 2.14** | 负 −0.06%（n=19） · 0 +0.24%（8） · 正 +0.52%（8） |
| `llm_sentiment` | +0.37（p=0.027） | 2.11 / 1.81 | 负 0.00%（22） · 正 +0.52%（8） |
| `p_up_1d` | +0.37（p=0.021） | 2.47 / 2.64 | |

**但不能当结论**：
- 这张表一共做了 8 特征 × 5 窗口 = 40 次检验，Holm 校正后最小 p = **0.39**；
- n=35，正情绪日只有 8 天；
- 它在时点上是可交易的（信号 ~08:30 已知，09:30 开盘入场，16:00 平仓），而 CORR.md 因为日期错位从来没测过这个窗口。

如果要追，正确做法是：**修正 `show_date` 后，把"A 开 → A 收"作为 h=0 窗口加进因子框架，并在新样本（11 月以后）上做一次预注册检验**，而不是在这 35 天上继续挖。

## 6. 覆盖与局限

- 窗口内 43 个交易日，36 天有当日节目，35 天被次日节目复盘。缺 9/23–9/24 与 10/12–10/16（上游无投稿）。
- 9 集是 45–80 分钟的短版，其余 135–150 分钟；均未覆盖 09:30 开盘。
- 抽取由 deepseek-v4-flash 单次完成（temperature 0）；方向字段可信度高，数字字段只在节目明确报数时填写
  （前日涨跌幅只报了 5 次，所以前日只评方向）。
- 宏观解释只用了 10Y/2Y/Brent 三个变量；美元指数数据源当时不可用（akshare 东财接口断连）。
- Nasdaq 期指未报时用 S&P×1.2 近似 QQQ（QQQ 对 SPY 的 β）；29 集有 Nasdaq 数字，只有 3 集用了近似。
