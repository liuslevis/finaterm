# PzQuantStock 投研工具 —— 复现规格说明（SPEC_OPUS48）

> 目标：复现截图中 **「委托成交查看器」** 这款 A 股 Level-2 逐笔数据回放 / 复盘研究工具的核心功能。
> Level-2 行情数据源：**富途 Futu OpenAPI（OpenD 网关 + futu-api SDK）**。

---

## 1. 概述

本工具是一款面向个人投资者 / 打板复盘的 **Level-2 逐笔数据回放与研究工具**，用于分析个股某一交易日「主力如何布局」——包括逐笔委托、逐笔成交、撤单行为、盘口十档变化、委托地图（时间-价格散点）、分时与日 K 走势。

核心使用场景（来自截图语音字幕）：
- 「我们看一下主力是如何布局」→ 逐笔委托 / 汇总统计
- 「然后剩下呢就是一直在吃吃吃」→ 委托地图观察主力吸筹
- 「然后我们看委托卖出」→ 按类型筛选卖单
- 「那我们再看一下他的日 K 走势吧」→ 日 K
- 「而且他的撤单追踪下盘口」→ 撤单追踪 + 盘口还原
- 「其实也就这一段的成交量 …… 决定了整个这一天的走势」→ 区间统计

### 1.1 技术形态
- 桌面客户端，Windows，多窗口（主窗 + 弹出子窗）。标题栏统一「PzQuantStock 投研工具」。
- 数据回放为主：给定 `代码 + 日期`，加载该日全量逐笔委托 / 逐笔成交 / 盘口快照，支持按时间「定位」「播放」「倍速」回放。
- 建议技术栈（可替换）：
  - 前端 UI：Electron + React + ECharts / Lightweight-Charts，或 PyQt6 + pyqtgraph。
  - 数据后端：Python，`futu-api` 拉取行情，落地为本地列式存储（Parquet / DuckDB）供回放。
  - 高频散点（委托地图动辄 9 万+ 笔）需用 Canvas/WebGL 或 pyqtgraph 保证流畅。

## 2. 数据模型

### 2.1 数据源：Futu OpenAPI
> **实现现状**：项目已获得真实的深交所/上交所 Level-2 逐笔原始数据（万得 Wind CSV，见 `README.md`），
> 实际实现直接解析该数据，**未使用 Futu**。本节的 Futu 方案保留为在无原始逐笔数据时的备选采集路径。

通过本地 `OpenD` 网关 + `futu-api` SDK 获取行情（需开通对应 Level-2 权限）：

| 功能 | Futu 接口 | 说明 |
|---|---|---|
| 订阅 | `subscribe(code, [SubType.ORDER_BOOK, SubType.TICKER, SubType.RT_DATA, SubType.K_DAY])` | 建立订阅 |
| 盘口十档 | `get_order_book(code, num=10)` | 卖十~卖一 / 买一~买十，价、量 |
| 逐笔成交 | `get_rt_ticker(code, num)` / `TickerHandlerBase` | 成交明细（时间/价/量/方向） |
| 分时 | `get_rt_data(code)` | 当日分时价 / 均价 / 成交量 |
| 日 K | `request_history_kline(code, start, end, ktype=KL_DAY)` | 复权 K 线 + 指标 |
| 基本信息 | `get_market_snapshot([code])` | 开盘、昨收、换手率、流通股 / 市值、涨跌停价 |

> **重要数据约束**：截图的核心是深交所 **逐笔委托（含撤单，类型=委托/成交/撤单）** 与「买方委托号 / 卖方委托号」的重建。Futu OpenAPI 实时提供逐笔成交与盘口快照，但 **逐笔委托明细 / 委托号级别的全量历史回放** 富途未必开放。实现时分两层：
> 1. **实时/近实时**：直接用 Futu 逐笔成交 + 十档盘口。
> 2. **逐笔委托与撤单重建**：若无原始逐笔委托源，则由 Level-2 逐笔成交 + 盘口增量差分 **推断**委托 / 撤单事件；若接入券商 Level-2 原始行情（如深交所 `逐笔委托`+`逐笔成交` 组播），则直接落地。规格以「逐笔委托 + 逐笔成交 + 撤单」为完整目标模型，Futu 为默认可得子集。

### 2.2 核心实体

**Stock（标的）**
```
code            股票代码，如 0****8.SZ / 6****5.SH（截图脱敏）
name            名称（脱敏为 ####）
```

**BasicInfo（基本信息，某交易日）**
```
open            开盘价      8.85
change_pct      当日涨幅    5.19%
turnover_rate   换手率      11.14%
hit_limit_up    是否涨停过  是/否
hit_limit_down  是否跌停过  是/否
prev_close      昨收        8.87
prev_change_pct 昨日涨幅    1.60%
float_shares    流通股      3.82亿
market_cap      市值        35.62亿
limit_up_price  涨停价      9.76
limit_down_price跌停价      7.98
```

**OrderEvent（逐笔事件，主表一行）**
```
seq             序号（1..N）
code            代码
time            时间 HH:MM:SS.mmm（毫秒级）
type            类型：委托 / 成交 / 撤单
side            方向：买 / 卖
price           价格
qty             数量（股）
amount          成交额（万），仅成交类有值
seq_no          序列号（交易所内部递增序号）
buy_order_id    买方委托号（无则 0）
sell_order_id   卖方委托号（无则 0）
timestamp       原始时间戳（纳秒/皮秒对齐，如 1762391700060000000）
```
> 类型/方向组合语义：委托买、委托卖、成交、撤买单、撤卖单。
> 「买方委托号 / 卖方委托号」用于把 委托→成交→撤单 串成同一订单的生命周期（见 2.3）。

**Order（订单生命周期，用于「追踪订单」）**
```
order_id        委托号
side            买/卖
events[]        {time, type(委托/撤单/成交), qty, price, 对手委托号}
total_qty       委托总量
filled_qty      成交量
canceled_qty    撤单量
status          未成交 / 部分成交 / 全部成交 / 已撤单
```

**OrderBookSnapshot（盘口十档快照）**
```
time
asks[10]        卖十..卖一：{price, qty}
bids[10]        买一..买十：{price, qty}
last_price      最新价
change_pct      涨跌幅
committee_ratio 委比 = (买量-卖量)/(买量+卖量)
committee_diff  委差 = 买量 - 卖量
total_bid_qty   委托买（合计）
total_ask_qty   委托卖（合计）
```

**Tick（逐笔成交）** `{time, side(买/卖), price, qty, amount}`
**KLineBar（日 K）** `{date, open, high, low, close, vol, amount, change_pct, turnover, amplitude, ma[]}`

## 3. 功能模块

### 3.1 主窗口：委托成交查看器（截图 0/3/5）

#### 布局
- **顶部工具栏**：`日期[20251106] [前一天][后一天]` · `跳转 HH:MM:SS:mmm [定位]` · `委托号[输入] ` · `[逐笔成交] [委托地图] [日K走势]`
- **左侧标的列表**：搜索框（代码/拼音首字母），列 `代码 | 名称`；选中项高亮（青色）。
- **中间主表**：逐笔事件表，列见 2.2 OrderEvent；随日期 / 筛选刷新；支持滚动、行选中、多选。
- **右侧面板**：统计筛选 + 基本信息 + 汇总统计 + 筛选记录 + `[重置]`。

#### 3.1.1 统计筛选（右上）
- 时间范围：`起始 HH:MM:SS.mmm` ~ `结束 HH:MM:SS.mmm`。
- 类型下拉（截图 3 展开）：`全部 / 成交 / 全委托 / 委托买 / 委托卖 / 全撤单 / 撤买单 / 撤卖单`。
- 数量区间：`最小(万) ~ 最大(万)`（如「委托卖 [*~*万]」）。
- 应用后：主表按条件过滤，右下「筛选记录」追加一条（如 `1. 委托卖[*-*万] (6813 条)`），且「汇总统计」按当前筛选集实时重算。
- `[重置]`：清空所有筛选，回到全量。

#### 3.1.2 汇总统计（右侧，按当前筛选集）
```
笔数        93584
总量/额     3.90亿 / 24.83亿
买入量/额   3.00亿 / 17.41亿
卖出量/额   9016.56万 / 7.42亿
买入额/卖出额(倍)   2.35
净额(买-卖)         9.99亿
买占比(%)           70.11
买入均价            5.80
卖出均价            8.23
```
计算：买入均价 = 买入额 / 买入量；买占比 = 买入量 / 总量；净额 = 买入额 − 卖出额。

#### 3.1.3 右键上下文菜单（截图 8）
在主表任意行右键：
- `追踪订单` → 打开「追踪订单」弹窗（3.5）
- `查看盘口` → 还原该时刻十档盘口（跳到委托地图右侧快照 / 弹窗）
- `日K信息`
- `统计选中范围`（多选行 → 汇总统计）
- `导出选中为 CSV...`
- `导出选中为 TXT...`

#### 3.1.4 定位 / 跳转
输入 `HH:MM:SS:mmm` 后点「定位」，主表滚动并高亮到最接近该时间戳的行；「委托号」输入可直接定位到该订单首行。

### 3.2 委托地图（截图 1/2/4）

子窗口标题：`委托地图 - <code>`。核心是 **时间(x) × 价格(y) 的委托散点图 + 左侧十档累积阶梯 + 右侧十档快照**，用于直观看主力挂单/撤单分布。

#### 3.2.1 散点主图（中）
- x 轴：交易时间（09:15 集合竞价 → 09:25 → 09:30 → 11:30/13:00 → 15:00）。
- y 轴：价格（自适应，覆盖当日全价域，如 7.98~9.76）。
- 气泡：一笔委托；**绿色=委托买入，红色=委托卖出**；气泡面积 ∝ 委托数量。
- 背景分区着色：集合竞价区 / 连续竞价区淡色分隔。
- Hover 提示框：
  ```
  价格：9.27
  买方委托
  总笔数：8
  委托总量：9400
  剩余数量：9400
  ```
- 回放控制：`[启动/暂停] [重置]` · `数量区间 ≥ 0 / ≤ 不限` · `倍速 ×10/×30...` · `定位 HH:MM:SS [定位]`；顶部显示当前回放时刻。

#### 3.2.2 十档累积阶梯（左表）
列：`B A/C | B Q | BID T | PX | ASK T | S Q | S A/C`
- `PX`：价格档位（灰列居中）。
- 买侧 `B A/C`（买方累计/净变化，+表示净买挂增加）、`B Q`（买队列量）、`BID T`（买挂单笔/时间戳标记）。
- 卖侧 `ASK T`、`S Q`、`S A/C` 对称。
- 随回放时刻动态刷新，反映各价位挂单的累积与消长（吸筹/砸盘可视化）。

#### 3.2.3 委托买入 / 委托卖出 明细（底部两表）
列：`委托时间 | 委托编号 | 委托数量 | 已成交数量 | 已撤单数量`，分别对应买 / 卖，随回放刷新。

#### 3.2.4 十档快照（右）
`十档快照 HH:MM:SS.mmm`：卖十~卖一、当前价（大字+涨跌幅+均价）、买一~买十，每档 `价格 | 量` 并带横向量能条；底部 `委比 / 委差` 与 `最新价/开盘价/涨跌幅/换手率/委托买/委托卖/涨停价/跌停价`。

## 4. 交互与回放引擎

- **时间轴回放**：统一回放时钟，`播放/暂停/上一帧/下一帧/复位/倍速(×10/×30)`；委托地图、逐笔成交、盘口快照均订阅同一时钟并同步刷新。
- **定位**：任意窗口可按 `HH:MM:SS(.mmm)` 精确定位并对齐所有联动视图。
- **性能**：单日事件 9 万+；主表虚拟滚动；散点用 Canvas/WebGL 批量绘制 + 按 `数量区间` 抽稀；盘口按时间索引二分查找。
- **底部状态栏**：进度条 + 当前时间 + 当前定位行摘要（代码/时间/类型/方向/价/量/额/委托号/时间戳）。

## 5. 数据管线（Futu 落地）

```
OpenD 网关 (需登录 + Level-2 权限)
        │
  futu-api SDK (Python)
        │  订阅/拉取：order_book / rt_ticker / rt_data / history_kline / snapshot
        ▼
  采集器 collector.py  ──►  本地存储 (Parquet 分区 by code/date) + DuckDB 索引
        │                         （逐笔事件表 / 盘口快照表 / K线表）
        ▼
  回放服务 replay_api  ──►  UI（按 code+date 加载，按时间窗查询/回放）
```

- 采集：交易时段实时订阅落地；盘后补拉当日快照与日 K。
- 逐笔委托/撤单：优先接入原始 Level-2 逐笔委托源；缺失时由成交+盘口差分推断并标注 `inferred=true`。
- 脱敏：UI 可选对 `代码/名称` 打码（截图中的 `0****8.SZ / ####`）。
